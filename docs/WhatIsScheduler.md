### Що робить Scheduler?

Ось його повний цикл (`runCycle` в scheduler.js):

```
┌─────────────────────────────────────────────┐
│  КРОК 0: Завантажити профіль                │
│  content.json → keywords → embedding vector │
└──────────────────┬──────────────────────────┘
                   ↓
┌──────────────────────────────────────────────┐
│  КРОК 1: FETCH                               │
│  sources.fetchAll() → HN + Reddit + Djinni   │
│  Результат: масив raw items                  │
└──────────────────┬───────────────────────────┘
                   ↓
┌──────────────────────────────────────────────┐
│  КРОК 2: VALIDATE                            │
│  validateIRBatch() → Zod перевіряє кожен item│
│  Невалідні — відкидаємо, логуємо             │
└──────────────────┬───────────────────────────┘
                   ↓
┌──────────────────────────────────────────────┐
│  КРОК 3: FILTER (семантичний)                │
│  searchEngine.findRelevant()                 │
│  Кожен item → embedding → cosine similarity  │
│  Залишаються тільки ті де score > threshold  │
└──────────────────┬───────────────────────────┘
                   ↓
┌──────────────────────────────────────────────┐
│  КРОК 4: SAVE                                │
│  db.insertItemsBatch() — зберігаємо в SQLite │
│  Дублікати по fingerprint ігноруються        │
└──────────────────────────────────────────────┘
```

**Тобто Scheduler = автоматизація всього пайплайну.** Він робить те ж саме що кнопка "🚀 Fetch Posts", але автоматично по cron розкладу (кожні 30 хвилин за замовчуванням).

Зараз у тебе scheduler закоментований → ти запускаєш цикл вручну через кнопку. Це нормально для розробки. Для продакшн — зазвичай вмикають cron щоб система сама оновлювала дані.
